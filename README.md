# 微博超话批量签到

基于移动端 API 的微博超话批量签到工具，支持多账户、WxPusher 通知推送，适用于华为云 FunctionGraph 部署或本地运行。

## 功能特性

- **移动端 API**：基于 `m.weibo.cn` 接口，签到 URL 由服务端返回，无需手动拼参数
- **多账户支持**：支持单账户或多账户批量签到
- **智能过滤**：可配置只签指定超话
- **防风控机制**：启动随机抖动、超话间随机延迟、账户间间隔
- **通知推送**：支持 WxPusher 推送签到结果
- **自动检测**：自动识别已签到超话并跳过

## 环境要求

- Python 3.6+
- 无需安装第三方依赖（仅使用标准库）

## 环境变量配置

| 变量名 | 说明 | 默认值 | 必填 |
|--------|------|--------|------|
| `WEIBO_COOKIE` | 单账户 Cookie | - | 二选一 |
| `WEIBO_COOKIES` | 多账户 Cookie（用 `@` 或换行或 `----` 分隔） | - | 二选一 |
| `START_JITTER_MAX` | 启动随机抖动上限（秒） | 180 | 否 |
| `DELAY_MIN` | 超话间随机延迟下限（秒） | 3 | 否 |
| `DELAY_MAX` | 超话间随机延迟上限（秒） | 6 | 否 |
| `ACCOUNT_INTERVAL` | 多账户之间基准间隔（秒） | 10 | 否 |
| `WEIBO_TOPICS` | 只签指定超话（逗号分隔） | 空（签全部） | 否 |
| `WXPUSHER_APP_TOKEN` | WxPusher 的 appToken（AT_开头） | - | 否 |
| `WXPUSHER_UID` | 接收者 UID（UID_开头，多人用逗号分隔） | - | 否 |
| `WXPUSHER_TOPIC` | WxPusher 主题 ID（数字） | - | 否 |

## 使用方法

### 本地运行

```bash
# 设置环境变量（Linux/macOS）
export WEIBO_COOKIE="你的Cookie"

# 运行脚本
python index.py
```

### 华为云 FunctionGraph 部署

1. 登录华为云控制台，进入 FunctionGraph 服务
2. 创建函数，运行时选择 Python 3.6+
3. 上传 `index.py` 文件
4. 在函数配置 -> 环境变量中设置上述配置项
5. 设置触发器（如定时触发器）

### 多账户配置示例

```bash
# 使用 @ 分隔
WEIBO_COOKIES="Cookie1@Cookie2@Cookie3"

# 使用换行分隔
WEIBO_COOKIES="Cookie1
Cookie2
Cookie3"

# 使用 ---- 分隔
WEIBO_COOKIES="Cookie1----Cookie2----Cookie3"
```

### 只签指定超话

```bash
WEIBO_TOPICS="超话1,超话2"
```

## 获取 Cookie

1. 在浏览器中登录微博（推荐使用移动端浏览器或 Chrome 移动端模式）
2. 打开开发者工具（F12）
3. 在 Network 标签页中找到任意请求
4. 复制请求头中的 `Cookie` 值

## 通知推送配置

### WxPusher 配置

1. 访问 [WxPusher](https://wxpusher.zjiecode.com/) 注册账号
2. 创建应用，获取 `appToken`
3. 关注 WxPusher 公众号，获取 `UID`
4. 将 `appToken` 和 `UID` 填入环境变量

## 注意事项

- Cookie 有效期有限，过期后需重新获取
- 建议设置合理的延迟参数，避免触发微博风控
- 首次使用建议先测试单账户，确认正常后再配置多账户
- 签到结果会自动跳过已签到的超话
